# Address Autofill

Chrome extension that fills address forms in **one click** with realistic test data for **243 countries and territories**.

Originally built to speed up QA testing of address forms (used by 15 people, saving ~2 minutes per form and reducing typing errors). This public version works on **any website**.

## Features
- 243 countries with flags and search (by name or code)
- 5 realistic addresses per country with local formats (phone, postal code, state)
- Auto-rotate addresses on every fill
- Edit and save your own addresses
- Smart field detection (`autocomplete`, name and id patterns)
- Keyboard shortcut (Ctrl+Shift+F) and dark mode

## Install
1. Open `chrome://extensions` and turn on **Developer mode**
2. Click **Load unpacked** and select this folder

> All data is fictional and meant for testing only.

**Tech:** JavaScript · Chrome Extensions (Manifest V3) · HTML/CSS
